HealthyMe – Personal Health Tracker

About the Project

HealthyMe is a personal health tracking application developed using Python and Streamlit. It helps users monitor their daily water intake, exercise activities, calorie consumption, and health progress. Supabase is used to store and manage health records.

Technologies Used

Python – Programming language

Streamlit – User interface

Supabase – Database management

OOP Principles

Encapsulation – Organizes related data and methods within classes.

Abstraction – Hides implementation details and simplifies application operations.

Inheritance – Allows classes to inherit properties and methods from other classes, where implemented.

Polymorphism – Allows methods or operations to behave differently depending on the object, where implemented.

Features

Personal profile management

Water intake tracking

Exercise tracking

Health progress monitoring

Health record storage

Purpose

HealthyMe aims to help users monitor their daily health activities, maintain health records, and track their progress toward personal health goals.
